# React Hands-On Projects

A collection of three React practical projects demonstrating **Props, State, and React Hooks**. These projects were developed as part of React Hands-On exercises.

## 📚 Projects

### 1. Student Profile Using Props

A reusable Student component that receives student information through **Props**.

**Details:**

* Student Name: Rahul
* Roll Number: 101
* Course: BCA
* College: ABC College

**Concept Demonstrated:** React Props

📁 Project Folder: `hands-on-1-student-profile`

🌐 **[Live Demo](https://muthukoornandini.github.io/student-profile-react/)**

---

### 2. Student Marks Using Props + State

A React application where student name and subject are received through **Props**, while marks are managed using **State**.

**Details:**

* Student Name: Rahul
* Subject: Java
* Initial Marks: 50
* Increase Marks button
* Decrease Marks button

**Concepts Demonstrated:**

* React Props
* React State
* `useState`
* Event Handling

📁 Project Folder: `hands-on-2-student-marks`

🌐 **[Live Demo](https://muthukoornandini.github.io/student-marks-react/)**

---

### 3. Login Form Using State

A simple login form that uses React **State** to manage username, password, and login messages.

**Features:**

* Username input
* Password input
* Login button
* Login validation
* Success and error messages

**Concepts Demonstrated:**

* React State
* `useState`
* Controlled Components
* Event Handling
* Conditional Logic

📁 Project Folder: `hands-on-3-student-login`

🌐 **[Live Demo](https://muthukoornandini.github.io/student-login-react/)**

## 🎯 Learning Objectives

These projects demonstrate the fundamental concepts of React:

* Creating React functional components
* Passing data using Props
* Managing data using State
* Using the `useState` Hook
* Handling user events
* Creating controlled form inputs
* Implementing basic conditional logic
* Deploying React applications using GitHub Pages
